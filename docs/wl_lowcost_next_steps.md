# WL 模乘器下一阶段实验计划

日期：2026-09-13。当前生产默认仍是 REDUCTION_IMPL=2。本次只完成关键路径审查、直接修正数公式验证与实验规划，未修改生产RTL，未运行新的Vivado实验。

## 研究目标与已确认基线

目标是在当前正确性、Montgomery表示和吞吐要求下，降低模乘器资源成本，并判断融合方法是否具有独立于低效基线的研究价值。当前Q=2^60-2^14+1，64位接口、合法输入0<=a,b<Q、R=2^64。

2026-09-12已布线的三版：原DSP版20DSP/911LUT/1497FF；普通移位版12DSP/993LUT/1629FF；融合版12DSP/917LUT/1557FF。内部OOC WNS分别1.746/2.691/1.683ns。这些是同一次条件下的参考，不是Fmax或整机时序签核。完整乘法回归8623拍，模乘14拍、II=1。

## 第一步：实现从输入低字直接生成修正数的可选版本

当前关键路径从round2输出到round3的correction寄存器控制，经过m生成、借位和修正数判断：10级逻辑、6个CARRY4，数据路径4.618ns，其中布线2.836ns。不能把全部时序代价都归因于逻辑，也不能由代数简化直接承诺提速。

原实现先求m，再求d，最终构造K=(m<<44)-d。新的数学候选直接从x=T[15:0]构造K。

```text
z = x[15:14] + x[1:0]          // 3 bits
u = {z[1:0], x[13:0]}          // 16 bits
v = {z[1:0], x[13:2]}          // 14 bits
delta = [x != 0] + z[2]        // 2 bits
K_low = (v + delta) mod 2^14

d_zero = (x == 0) || ((x[13:2] == 4095) && (z == 3))

K_upper = 0                   if x == 0
          4 - x[1:0]          if d_zero and x != 0  // 3-bit result
          ~u                  otherwise
K_middle = 0 if d_zero else 30 ones
K = {K_upper[16], K_middle[30], K_low[14]}
```

这里delta先在2位内求和，再做一次14位加法；d_zero与上部修正并行生成，不依赖这次14位加法的结果。保留原单轮两拍：第一拍寄存T_high与K，第二拍计算T_high+K。

数学证据：65536种低字×3组高位共196608项均与独立完整参考`((T+m*Q)>>16)-(T>>16)`一致；参考根据Q独立求逆生成m。脚本及JSON位于 `reports/wl_lowcost_modmul/next_step/direct_x_correction_audit.*`。这尚未证明RTL正确性、DSP映射、CARRY4数量或时序。

实施顺序：保存现有已测版本的源文件快照；新增可选实现，先保留默认2；增加与旧版同参考、同延迟的并行测试；通过后只跑新候选的独立综合和布局布线。检查真实最差路径，不仅检查汇总WNS。

本轮硬条件：结果一致、单轮2拍、完整14拍、II=1。资源目标是保持12DSP，LUT不超过当前917；时序目标先恢复至原版同条件内部裕量，再争取接近普通移位版。目标不是已达成结果，也不是论文录用门槛。若出现其他资源代价，完整报告，不强称全面更优。

后续正式比较需补齐一致的OOC时钟来源/边界约束，或使用统一注册边界封装；若改变时钟条件，应重测参与比较的基线。不要将当前未指定HD.CLK_SRC的WNS当作论文Fmax。

## 第二步：补足合理的已有方法对照

仅优于原20DSP版或自有普通移位版，不能充分证明研究贡献。主比较至少包含以下约减结构，并统一使用同一12DSP整数乘法前端：

| 方法 | 当前q的适配方式 | 比较目的 |
|---|---|---|
| 原DSP版 | 4×16位WL，显式DSP常乘 | 工程基线 |
| 普通移位版 | 4×16位WL，常乘移位特化 | 分离常规特化收益 |
| 当前融合版和直接输入候选 | 4×16位WL，融合修正数 | 评价融合机制与实现改进 |
| 低字为1的WLM | 14+14+14+14+8位五轮，总计64位；允许普通移位特化 | 与更适合该模数低位结构的已有方法比较 |
| 通用单次Montgomery REDC | R=2^64，使用当前真实q与q'的移位加减常乘 | 判断分字约减相比整字约减的收益 |

低字为1的WLM中，前四轮Q_high=2^46-1，最后8位轮Q_high=2^52-2^6，均可采用常规移位减法，不能故意只做强制DSP的弱实现。

通用REDC使用：

```text
q' = 0x0efffbffefffbfff
   = -1 -2^14 -2^28 -2^42 -2^56 +2^60 (mod 2^64)
m = T_low64 * q' (mod 2^64)
u = (T + m*Q) >> 64
```

这是真实q下的通用REDC特化，不能称为原论文的Proth Montgomery-Shift实现。

所有方案保持相同q、输入范围、输出abR^-1 modq、器件/工具及II=1。允许已有方法选择合适流水级数，报告真实延迟，不能为强制14拍而人为削弱对手。分别记录约减器和完整模乘资源；记录同约束布线时序，有需要再扫频，不能由WNS反算正式Fmax。

参考：

- [2020/665, Montgomery-friendly primes and applications to cryptography](https://eprint.iacr.org/2020/665.pdf)，特殊模数的WL方法。
- [2024/1890, 2025修订版](https://eprint.iacr.org/2024/1890)，WLM-Mixed、Montgomery-Shift等方法。
- [作者wordred.sv](https://github.com/cisec-su/modmul-hdl/blob/main/src/monty/wordred.sv)，公开实现对照。

当前q的v2(q-1)=14，而模数为60位；2025文献的低成本Proth配置要求的低位条件与此不同，不能直接将其3DSP约减数字套入本表。普通伪Mersenne约减输出ab modq，与现有Montgomery接口不同，若比较必须计域转换或另设完整普通数域实验。

## 第三步：用模数族检验可推广性

扩展方向q=2^n-c*2^s+1，初期采用编译时参数，而不是立即加入运行时模数切换。已有数学枚举在n=55..64、s=13..15、c为1..15奇数的240个候选中找到11个素数；这些满足4096点负循环NTT的根阶条件。选代表性的不同n/s/c先做硬件，再扩大测试。

必须同时给出：适用模数/字宽条件，字段宽度与溢出界限，小常数c*m的额外成本，流水安排，以及多个模数上的真实结果。当前直接输入简式专用于n=60,s=14,c=1，不能未经证明就套用于整个模数族。

## 第四步：整机确认与研究决策

选出单模块方案后运行完整回归，再用当前 `natural_ab_raw_pre_shared` 配置重测整机综合和布局布线，保存新目录与源码哈希。确认26个实例是否实际达到312DSP，以及LUT/FF/BRAM、布线拥塞、150MHz目标下时序和完整任务延迟。保持同一系统功能与缓存计费边界。

继续作为论文核心的依据：对合理已有方法，在预先说明的应用约束下获得明确的资源/性能优势，并能在代表性模数上复现，且整机能保留收益。没有必要要求所有指标同时最优，但必须说明取舍。若收益只存在于原先强制DSP的基线，或推广代价吃掉优势，则保留为工程优化，不把它单独作为论文主贡献。
